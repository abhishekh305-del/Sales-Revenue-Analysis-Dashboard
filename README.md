# 📊 Sales & Revenue Analysis Dashboard

## Internship Project

This project was completed as part of my internship at **Thiranex**.

## Project Overview

The Sales & Revenue Analysis Dashboard analyzes sales and revenue data using interactive visualizations to help monitor business performance and support data-driven decision-making.

## Features

- 📈 Total Sales KPI
- 💰 Total Profit KPI
- 🛒 Total Orders KPI
- 📊 Sales Trend Analysis
- 🏆 Top Performing Products
- 🌍 Sales by Region
- 📦 Category-wise Sales Distribution
- 🎛 Interactive Filters & Slicers

## Tools Used

- Microsoft Power BI
- Microsoft Excel

## Project Files

- Sales Dataset (.xlsx)
- Dashboard (.xlsx / Power BI)
- Dashboard Screenshots

## Learning Outcomes

- Data Visualization
- Dashboard Development
- Business Intelligence
- KPI Analysis
- Business Reporting
- Data-Driven Decision Making
